# IPL Match & Player Performance Analytics Dashboard

An interactive Excel-based analytics project for analyzing IPL match,
player, team, and venue-level performance.

## 🛠️ Tools & Techniques

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- KPI Analysis
- Data Visualization

## 📊 Project Analysis

The dashboard analyzes:

- Player runs and wickets
- Strike rate
- Bowling economy
- Team performance
- Match outcomes
- Venue-wise performance
- Player role-based performance

## 📈 Dashboard Features

- Interactive KPI cards
- PivotTables and PivotCharts
- Player-wise performance analysis
- Team performance analysis
- Venue filtering using slicers
- Role and team-based filtering
- Comparative player analysis

## 📁 Workbook Structure

| Sheet | Purpose |
|---|---|
| `fact_match` | Match-level data |
| `fact_player` | Player performance data |
| `dim_player` | Player information |
| `dim_team` | Team information |
| `dim_venue` | Venue information |
| `Player_summary` | Player-level analysis |
| `Team_summary` | Team-level analysis |
| `player_performance dashboards` | Interactive player dashboard |
| `Team_performance charts` | Team performance visualizations |

## 🎯 Objective

The objective of this project is to transform IPL data into meaningful
visual insights that help compare player and team performance and identify
performance trends.
